# Expedice Launcher

Český komunitní launcher pro společné Minecraft balíčky a ovládání vlastního serveru.

**[Web a stažení pro Windows](https://expedice-launcher-atrep.atrep-filip.chatgpt.site)** · [Nejnovější vydání](https://github.com/atrep123/expedice-launcher/releases/latest)

## Instalace

1. Stáhni [ExpediceLauncher-Setup.exe](https://github.com/atrep123/expedice-launcher/releases/latest/download/ExpediceLauncher-Setup.exe).
2. Vyber „Jen hrát“ nebo „Hrát a hostovat server“.
3. Zkontroluj velikost a potvrď stažení. Potom dokonči průvodce v launcheru.
4. Příště stačí zástupce **Expedice Launcher** na ploše.

K dispozici je také [úplný instalátor pro obě role](https://github.com/atrep123/expedice-launcher/releases/latest/download/ExpediceLauncher-Offline.exe). První příprava Minecraftu stále vyžaduje internet.

Prvním balíčkem je **Stargate Expedice** pro Minecraft Java 1.20.1 / Forge. Název launcheru je obecný pro budoucí balíčky.

## Aktualizace

Launcher nejprve zobrazí změny, velikost stažení a potřebné místo. Samotná kontrola aktualizací balíčky nestahuje. Stažení potvrdí hráč; přerušené stahování lze později dokončit. Soubory se průběžně zapisují na disk a ověřují podpisem manifestu a SHA-256. Velké soubory mohou mít několik samostatně ověřených částí.

Původní adresa `atrep123/stargate-expedice-updates` je přesměrovaná. Starší launchery dostanou malé přechodové vydání 2.0.0 přes `update.json`; nový launcher používá `update-v2.json`. Zachovává se původní herní složka, mapy, přihlášení a osobní nastavení.

## Přístup a soukromí

Veřejné stažení nedává přístup k soukromému hernímu serveru. Náš společný server chrání seznam povolených hráčů a osobní přihlášení. Hesla patří do soukromých pozvánek; nejsou součástí vydání. Světy, účty, klíč Playit ani soukromý podpisový klíč se nezveřejňují.

Windows 10/11, 64 bit. Launcher je zdarma. Pro běžné přihlášení přes Microsoft potřebuješ licenci Minecraft Java Edition. Instalátor zatím nemá komerční podpis vydavatele pro Windows a může vyvolat upozornění SmartScreen.

Nejde o oficiální produkt Minecraftu. Projekt není spojený s Mojangem ani Microsoftem.
